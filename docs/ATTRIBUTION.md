## Platform

CrossPoint and FreeInk maintainers created the underlying e-reader firmware, UI and hardware abstractions. The Razor-Crest fork currently contains experimental support for SD theme rendering; no endorsement by CrossPoint is implied.

## Theme tooling

HALO's collection-specific `theme.json`, manifest, and reusable host validators/converters in this repository provide a declarative format for theme-capable firmware. The public code portions do not imply any license to redistribute third-party images/fonts independent of their original terms.
